# Комплект OpenCode для разработки на 1С

Комплект предназначен для проектов, подготовленных `dev-agent`.

## Состав

- `rules/` — самостоятельные project rules без внешнего корпуса MCP;
- `commands/` — команда запуска YAxUnit.
- `manifest.json` — пути установки и SHA-256 управляемых файлов.

## Принципы

- `bsl-language-server` — Обязательный MCP разработки с официальным набором инструментов для анализа и проверки кода.
- `1c_mcp_toolkit` (1C MCP Toolkit) — опциональный источник фактических данных, журнала и справки BSL. Его подключение настраивается в локальном `opencode.jsonc`; отсутствие не блокирует работу. Политика безопасности находится в `AGENTS.md`, существующие правила от этого MCP не зависят.
- Метаданные и ИБ обслуживаются granular skills `cc-1c-skills`; API БСП — skill `bsp`.
- `rules/` не загружается целиком: корневой `AGENTS.md` и команды выбирают только применимые правила по типу задачи.

Установка и обновление выполняются по `AI_STAND_SETUP.md`.
